# คอมเมนต์ GitHub PR และข้อความส่วนตัว

## คอมเมนต์และ @กล่าวถึง

- เปิดงานแล้วขยาย **คอมเมนต์และ @กล่าวถึง**
- กดชื่อสมาชิกในโปรเจกต์เพื่อใส่ @ และส่งการแจ้งเตือนในเว็บ
- เฉพาะเจ้าของงานและสมาชิกโปรเจกต์ปัจจุบันอ่านหรือเขียนคอมเมนต์ได้ เจ้าของคอมเมนต์ลบของตัวเองได้

## Pull Request ที่เชื่อมกับงาน

- แนบ URL แบบ `https://github.com/owner/repo/pull/12` ในงานหรือบอร์ดทีม
- คนที่มีสิทธิ์แก้โปรเจกต์แนบหรือเอาลิงก์ออกได้ สมาชิกแบบอ่านอย่างเดียวดูได้
- หากบัญชีเชื่อม GitHub และ GitHub App มีสิทธิ์ `Pull requests: Read` และ `Checks: Read` จะเห็นสถานะ PR, รีวิว, ไฟล์ที่เปลี่ยนและผลตรวจ
- ถ้าข้อมูลบางส่วนไม่พร้อม ให้ตรวจการติดตั้ง GitHub App และสิทธิ์ repository ใน GitHub แล้วเชื่อมบัญชีใหม่ตามที่ GitHub แจ้ง

## ข้อความส่วนตัว

- ไปที่ **ทีมและโค้ด → ข้อความส่วนตัว** แล้วกรอกอีเมลบัญชี TaskFlow ของผู้รับ
- รองรับข้อความ รูป PNG/JPEG/GIF/WebP และไฟล์อื่นที่ดาวน์โหลดเป็นไฟล์แนบ
- จำกัดไฟล์ละ 5 MB, พื้นที่ไฟล์ที่ส่ง 100 MB ต่อบัญชี และรวม 4 GB สำหรับระบบ ป้องกันการใช้พื้นที่เกิน Turso Free ที่มี 5 GB ตามราคาปัจจุบัน
- มีตัวเลขข้อความใหม่ในกระดิ่งแจ้งเตือน และเมื่อเปิดห้องจะบันทึกว่าอ่านข้อความแล้ว หน้าจอรีเฟรชทุก 15 วินาทีเมื่อเปิดห้อง
- ไฟล์อยู่ในฐานข้อมูล Turso ไม่อยู่บนดิสก์ของ Render; มีเพียงผู้ร่วมบทสนทนาเท่านั้นที่เปิดได้ ผู้ส่งลบข้อความและไฟล์ที่แนบไว้ได้

การเปลี่ยนแปลงฐานข้อมูลใช้ `CREATE TABLE IF NOT EXISTS` ตอนเปิดเซิร์ฟเวอร์ ข้อมูลเดิมไม่ถูกลบ
