# ผู้ช่วย AI ใน TaskFlow

ผู้ช่วยใช้ Gemini API เพื่ออ่าน **ข้อความที่ผู้ใช้พิมพ์ในช่องแชท รวมข้อความก่อนหน้าสูงสุด 4 รายการ** แล้วเสนอคำสั่งให้ตรวจ ก่อนเปลี่ยนข้อมูลทุกครั้ง ข้อมูลบัญชี รายการงาน โปรเจกต์ และร่าง สก.09 ที่มีอยู่แล้วไม่ถูกส่งเป็นบริบทให้ Gemini ข้อความที่ผู้ใช้พิมพ์เองอาจมีข้อมูลส่วนตัว จึงมีช่องยินยอมก่อนส่ง และ Gemini Free Tier อาจใช้เนื้อหาเพื่อปรับปรุงบริการตาม [เงื่อนไขราคา Gemini](https://ai.google.dev/gemini-api/docs/pricing)

## ตั้งค่า

1. สร้าง API key ใน [Google AI Studio](https://aistudio.google.com/app/apikey) และตรวจว่าโปรเจกต์ใช้ Free Tier ได้
2. เพิ่ม `GEMINI_API_KEY=...` ในไฟล์ `.env` ที่โฟลเดอร์หลักของโปรเจกต์ หรือกำหนดเป็น environment variable บนเซิร์ฟเวอร์ ห้ามใช้ `VITE_` และห้ามใส่ key ในโค้ดฝั่งเว็บ
3. ค่าเริ่มต้นของโมเดลคือ `gemini-3.5-flash-lite` เปลี่ยนได้ด้วย `GEMINI_MODEL` หากต้องการ
4. รีสตาร์ต API ด้วย `npm.cmd run dev` แล้วเข้าสู่ระบบ กดปุ่ม **ถาม AI** มุมขวาล่าง

ไม่ต้องตั้งค่า n8n สำหรับแชทนี้ โควตา Free Tier มีข้อจำกัด และบางโปรเจกต์อาจไม่มีสิทธิ์ใช้งาน ดูโควตาปัจจุบันใน [Google AI Studio](https://aistudio.google.com/)

## ขอบเขตคำสั่ง

- เพิ่ม แก้ ลบ และค้นหางาน; ดูจำนวนงาน; สร้าง แก้ และลบโปรเจกต์
- แก้ชื่อ ชื่อเล่น เบอร์โทร; แก้หัวข้อหลักในร่าง สก.09; อ่านการแจ้งเตือนทั้งหมด
- ผูกลิงก์ GitHub Issue หรือ Pull Request กับงาน; สั่งรัน รันซ้ำ หรือยกเลิก pipeline เมื่อระบุ repository และ ID ชัดเจน
- เปิดหน้าที่เกี่ยวข้องกับคำสั่งอื่น เช่น รูปโปรไฟล์ อีเมล การเชื่อม Google/GitHub, API key, รายละเอียด GitHub และ PDF สก.09

การแก้ไขข้อมูลทุกครั้งต้องกด **ยืนยันและบันทึก** ก่อน คำสั่งที่อ้างงานหรือโปรเจกต์เดิมต้องระบุชื่อให้ตรง หากชื่อซ้ำ ระบบจะให้แก้ผ่านหน้ารายการเพื่อเลี่ยงการเปลี่ยนผิดรายการ คำสั่งที่เกี่ยวกับ OAuth รหัสผ่าน ไฟล์ภาพ และการดาวน์โหลด PDF ใช้หน้าจอเฉพาะของฟังก์ชันนั้น

ในหน้า **บันทึกการทำงาน** สามารถพิมพ์ “งานที่ทำ” แล้วติ๊กยินยอมให้ส่งข้อความช่องนี้ไป Gemini จากนั้นกด **ให้ AI ช่วยคิด** เพื่อร่าง “ผลลัพธ์ / สิ่งที่ได้เรียนรู้” ระบบแสดงร่างให้ตรวจก่อน ผู้ใช้เลือกนำไปใส่ช่องผลลัพธ์ แก้ไขเอง แล้วกดบันทึกตามปกติ การสร้างร่างไม่บันทึกข้อมูลอัตโนมัติ และไม่ส่งข้อมูลบัญชีหรือบันทึกอื่นเป็นบริบท

ตัวอย่าง:

```text
เพิ่มงานส่งรายงานวันที่ 7 มกราปีหน้า ความสำคัญสูง
เปลี่ยนวันส่งงานชื่อ "ส่งรายงาน" เป็นวันศุกร์หน้า
สร้างโปรเจกต์ชื่อ ฝึกงาน
แก้ชื่อเล่นเป็น นัท
ใส่ชื่อบริษัท ABC ในร่าง สก.09
```
