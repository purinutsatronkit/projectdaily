# อีเมล ข้อมูลบัญชี และการสำรอง

## ยืนยันอีเมล

เมื่อสมัครด้วยอีเมลและตั้ง SMTP แล้ว ระบบส่งลิงก์ยืนยันอายุ 15 นาทีโดยอัตโนมัติ หากยังไม่ยืนยัน ให้ไปที่รูปโปรไฟล์ → ตั้งค่าบัญชี → **ส่งลิงก์ยืนยันอีเมลปัจจุบัน** จากนั้นเปิดลิงก์และกด **ยืนยันอีเมล** ลิงก์ใช้ได้ครั้งเดียว

การเปลี่ยนอีเมลต้องกรอกรหัสผ่านเดิม ระบบส่งลิงก์ไปที่อีเมลใหม่ อีเมลเดิมยังใช้เข้าสู่ระบบและรับการแจ้งเตือนจนกว่าจะกดยืนยัน ที่อยู่ใหม่ต้องยังไม่มีบัญชีอื่นใช้ บัญชีที่เข้าด้วย Google ถือว่ายืนยันอีเมลที่ Google ให้แล้ว หากต้องเปลี่ยนอีเมลและยังไม่มีรหัสผ่าน ให้ใช้ “ลืมรหัสผ่าน” เพื่อสร้างรหัสผ่านก่อน

ระบบต้องมี SMTP_USER และ SMTP_PASS ตาม [คู่มือลืมรหัสผ่าน](password-reset-gmail.md) จึงส่งลิงก์ได้ หาก SMTP ไม่พร้อม การสมัครยังทำได้ แต่สถานะจะยังไม่ยืนยันและต้องกลับมาขอลิงก์ภายหลัง ปัจจุบันสถานะยืนยันอีเมลเป็นข้อมูลบัญชี ยังไม่ได้ปิดกั้นการใช้งานของบัญชีเก่าหรือบัญชีที่ยังไม่ได้ยืนยัน ซึ่งควรเป็นนโยบายก่อนเปิดรับสมัครทั่วไป

## ส่งออกและลบบัญชี

ตั้งค่าบัญชี → **ดาวน์โหลดข้อมูลของฉัน** จะได้ JSON รวมโปรไฟล์ รูปภาพ งาน โปรเจกต์ ลิงก์ Issue/PR ร่าง สก.09 และประวัติการแจ้งเตือน/คำสั่ง pipeline ไม่มีรหัสผ่านหรือ GitHub token ไฟล์มีข้อมูลส่วนตัว ควรเก็บในที่ปลอดภัย

การลบบัญชีใช้ปุ่ม **ลบบัญชีของฉัน** ต้องกรอกอีเมลและ `DELETE` รวมถึงรหัสผ่านปัจจุบัน สำหรับบัญชี Google ที่ยังไม่มีรหัสผ่าน ต้องเพิ่งเข้าสู่ระบบภายใน 10 นาที การลบลบข้อมูล TaskFlow ในฐานข้อมูลปัจจุบันอย่างถาวร และออกจากระบบ ต้องถอน GitHub App/authorization จาก GitHub ต่างหาก สำเนาที่เคยสำรองไว้จะยังอยู่จนกว่าผู้ดูแลจัดการตามนโยบายสำรอง

## สำรองและกู้คืนฐานข้อมูล

ขณะ API เปิดอยู่ สามารถรัน:

```powershell
npm.cmd run db:backup
```

ระบบใช้ SQLite `VACUUM INTO` สร้างสำเนาที่สอดคล้องกันใน `D:\project\backups` แล้วตรวจ `PRAGMA integrity_check` ไฟล์สำรองไม่เข้า Git และมีข้อมูลของผู้ใช้ทุกคน ควรเข้ารหัส/จำกัดสิทธิ์เมื่อเก็บนอกเครื่อง สำรอง `.env` โดยเฉพาะ `OAUTH_TOKEN_KEY` แยกในที่ปลอดภัย ถ้าคีย์หาย GitHub token ที่สำรองไว้ใช้ไม่ได้และต้องเชื่อมใหม่

ก่อนแทนที่ฐานข้อมูลใช้งานจริง ให้หยุด API แล้วทดลองคัดลอกไฟล์สำรองไปยังไฟล์ใหม่ก่อน:

```powershell
npm.cmd run db:restore-check -- backups\taskflow-ชื่อไฟล์.sqlite data\restore-test.sqlite
```

คำสั่งนี้ตรวจต้นฉบับ คัดลอกไปยังไฟล์ **ใหม่เท่านั้น** และตรวจไฟล์ปลายทาง ไม่เขียนทับฐานข้อมูลจริง หากต้องกู้คืนจริง หลังตรวจสำเนาและหยุด API ให้เก็บไฟล์ฐานข้อมูลเดิมไว้ก่อน จากนั้นนำสำเนาที่ตรวจผ่านไปเป็น `DATABASE_PATH` ที่ต้องการและเปิด API ตรวจ `/api/health`, บัญชี และงานที่สำคัญ ข้อมูลจาก `.env` ต้องตรงชุดที่สำรองไว้ด้วย
